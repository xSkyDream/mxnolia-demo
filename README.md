# Mxnolia — démo de prospection

Maquette fonctionnelle du site boutique de Mxnolia (vinyles peints à la main), réalisée par SkyLab.
Paiement **fictif** : aucune donnée n'est enregistrée ni envoyée.

- `npm install` puis `npm run dev` pour lancer en local
- `npm run build` génère le site statique dans `dist/`
- Déploiement : Vercel (préréglage Vite, aucune configuration)

Les pages sont générées depuis les maquettes Claude Design par `tools/convert.py`.
